🔴 Critical Issues

1. Bare except clause in Ollama launcher

# CURRENT — dangerous
try:
    subprocess.Popen([path, "serve"], ...)
except:
    pass

This silently swallows all exceptions — including KeyboardInterrupt and SystemExit. Real failures become invisible. Fix:

except (OSError, FileNotFoundError, PermissionError) as e:
    logging.warning(f"Failed to start Ollama at {path}: {e}")

2. Multiple inheritance MRO collision risk

Python's Method Resolution Order means if any two of NovaTTS, NovaSelfImproveUI, or NovaRouter define the same method name, only one wins — silently, with no warning. This is a latent bug that could manifest in subtle, hard-to-trace ways.

Recommendation: Add explicit MRO documentation, or refactor toward composition over inheritance.

🟡 Moderate Issues

3. nova_state.json — no schema validation

State is created if missing, but there's no validation of its structure on load. A corrupted or outdated state file could cause silent downstream failures.

# Recommended addition
def _validate_state(self, state: dict) -> bool:
    required_keys = ["memory", "location", "session_id"]
    return all(k in state for k in required_keys)

4. Tool Registry — no audit mode

tools/tool_registry.py exists but has no health-check or introspection endpoint. If a tool fails to register, Nova silently loses that capability with no indication.

# Recommended addition at startup
registry.audit()  # logs all registered tools + status

5. self._latex_window_enabled = False — hardcoded default

The LaTeX window is disabled by default with no visible UI toggle. Users may not know it exists or how to enable it.

6. code_history directory — unbounded growth

self.code_history_dir = "code_history"
os.makedirs(self.code_history_dir, exist_ok=True)

No pruning logic. This directory will grow indefinitely over time. A "keep last N files" policy should be added.
