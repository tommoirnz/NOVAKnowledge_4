🔍 Nova Self-Inspection — Code Improvement Analysis

Based on actual source code inspection of nova_assistant_v1.py

🔴 Critical Issues

1. Bare except Clauses — Silent Failure Risk

# Current code:
try:
    r = requests.get(url, timeout=2)
    if r.status_code == 200: return True
except:
    continue

Problem: Catches everything — including KeyboardInterrupt, SystemExit, and memory errors. Bugs become invisible.

Fix:

except (requests.ConnectionError, requests.Timeout, requests.RequestException):
    continue

2. No State Corruption Recovery

# Current code:
if not os.path.exists("nova_state.json"):
    self.save_state()

Problem: Only checks existence, not validity. A corrupt or truncated JSON file will crash on load with zero recovery.

Fix:

def load_state_safe(self):
    try:
        with open("nova_state.json") as f:
            return json.load(f)
    except (json.JSONDecodeError, IOError):
        self.log("[STATE] Corrupt state file — resetting to defaults")
        self.save_state()
        return self.default_state()

3. Multiple Inheritance — MRO Collision Risk

# Current code:
class NovaAssistant(NovaTTS, NovaSelfImproveUI, NovaRouter):

Problem: Python's Method Resolution Order (MRO) with 3+ base classes is a debugging nightmare. State collisions between mixins are silent and nasty.

Fix: Prefer composition over inheritance:

class NovaAssistant:
    def __init__(self):
        self.tts = NovaTTS()
        self.router = NovaRouter()
        self.self_improve = NovaSelfImproveUI()

Explicit. Testable. No MRO surprises.

4. System Prompt Formatting Risk

# Current code:
SYSTEM_PROMPT = """...Today's date is {date}. You are located in {location}."""

Problem: If .format() is called incorrectly or location hasn't loaded yet, you get either a raw {location} in the prompt or a KeyError.

Fix: Make it a property:

@property
def system_prompt(self):
    return self.SYSTEM_PROMPT.format(
        date=datetime.now().strftime("%A %d %B %Y"),
        location=self.suburb or "Birkdale"
    )

🟠 Performance Issues

5. Blocking Connectivity Check

r = requests.get(url, timeout=2)

Problem: Runs synchronously. A 2-second timeout × multiple URLs = potential UI freeze.

Fix: Move into a daemon thread with a callback:

def _check_connectivity_async(self, callback):
    def _check():
        result = self._is_connected()
        self.root.after(0, lambda: callback(result))
    threading.Thread(target=_check, daemon=True).start()

6. Hardcoded Version String

__version__ = "3.0.0"
__author__ = "Dr Tom Moir"

Problem: Manually maintained. Drift between code, UI display, and logs is inevitable.

Fix:

from importlib.metadata import version
__version__ = version("nova-assistant")

7. Manual Unicode Replacement Table — Fragile & Incomplete

replacements = {
    "\u201C": '"', "\u201D": '"',
    "\u2018": "'", "\u2019": "'",
    "\u2014": "-", "\u2013": "-",
    "\u2026": "...", "\u00d7": "*",
    "\u00f7": "/", "\u2192": "->",
}

Problem: A manual dict that grows forever. Already missing dozens of Unicode characters.

Fix: Use the standard library:

import unicodedata
clean = unicodedata.normalize('NFKC', code)

One line. Handles thousands of cases. No maintenance required.

🟡 Reliability Gaps

8. Scattered os.makedirs Calls

os.makedirs(self.code_history_dir, exist_ok=True)
os.makedirs("web_images", exist_ok=True)

Fix: Group them for clarity and auditability:

for d in ("code_history", "web_images", "downloads", "downloaded_images"):
    os.makedirs(d, exist_ok=True)

9. Double topmost Workaround

self.root.attributes("-topmost", False)
self.root.after(10, lambda: self.root.attributes("-topmost", False))

Problem: The after(10) is clearly a workaround for a focus/window ordering bug — a symptom, not a fix. Investigate why topmost is being set at all and handle window focus correctly post-init.

10. Eager LaTeX Window Instantiation

self._latex_window_enabled = False
self.latex_win.withdraw()

Problem: The window is created then immediately hidden — wasted memory and init time.

Fix: Lazy instantiation:

self._latex_win = None

def get_latex_window(self):
    if self._latex_win is None:
        self._latex_win = LatexWindow(...)
    return self._latex_win

11. No Structured Logging

self.log("[STATE] Creating initial state file")
self.log(f"[SYSTEM] Model: {self.ai.model}")

Problem: Custom log method with bracket-prefixed strings. No log levels, no file output, no timestamps.

Fix:

import logging
logger = logging.getLogger("nova")
logger.info("Creating initial state file")
logger.debug(f"Model: {self.ai.model}")

12. Unbounded Code Block List — Memory Leak Risk

self.code_blocks = []  # List of (frame, language) tuples

Problem: Every code block in the conversation is appended. Long sessions = memory leak as Tkinter frames accumulate.

Fix:

from collections import deque
self.code_blocks = deque(maxlen=50)
